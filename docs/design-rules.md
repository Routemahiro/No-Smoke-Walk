# No-Smoke Alert デザインルール（トップページから抜き出し）

トップページ（/）の見た目をそのまま「正解」として決めたルールです。
新しいページは、このルールと共通部品（frontend/src/components/ds）だけで作ります。

## 色
- 背景：うすい青→うすい緑のグラデーション（blue-50 → green-50）
- 箱（カード）：白
- ロゴ・サイト名：紺 #0F2346
- 文字：見出しは濃いグレー（gray-900）、本文はグレー（gray-600）、注記は薄いグレー（gray-500）
- アクセント：青（ボタン blue-600、リンクと小見出し blue-700）
- 種類の色は「小さな丸・アイコンの下地」だけに使う。歩きタバコ＝赤、立ち止まり喫煙＝オレンジ。ボタン全面を派手な色で塗らない
- お知らせ：案内＝うすい青、エラー＝うすい赤、完了＝うすい緑（枠つき）

## 文字の大きさ
- ページの大見出し：24px 太字（PCは30px）
- 箱の見出し：18px やや太字
- 本文：14px、行間ゆったり
- 注記・出典：12px

## 形
- 角の丸み：箱もボタンも「rounded-lg」（8px）でそろえる。丸すぎる角（xl 以上）は使わない
- 影：普段は弱い影（shadow-sm）、押せるものはホバーで少し強く（shadow-md）
- 枠：細い1本線
- 余白：箱の中は20px（大きい箱は24px）、箱どうしは16〜24px

## ボタン
- いちばん大事な操作：青で塗った横いっぱいのボタン（1画面に1つまで）
- その他：白地に青文字・枠つき
- 報告ボタン（すぐ報告）：白い箱に色つきアイコン＋名前＋短い説明

## 部品
- Panel：白い箱
- Notice：お知らせ（案内／エラー／完了）
- PrimaryLink：青い主ボタン
- ds：上の色・文字・形のクラスをまとめたもの
